# AI-POWERED DIESEL GENERATOR USAGE MONITORING SYSTEM

Welcome to the **AI-Powered Diesel Generator Usage Monitoring System** college mini-project.

The entire source code, dataset, tests, and web application are organized inside the `DG_Monitoring_System/` directory:

- **Frontend:** `DG_Monitoring_System/frontend/` (`index.html`, `style.css`, `script.js`)
- **Backend:** `DG_Monitoring_System/backend/` (`app.py`, `services/`, `data/`, `tests/`, `requirements.txt`)
- **Full Documentation:** Refer to [`DG_Monitoring_System/README.md`](DG_Monitoring_System/README.md) for detailed architecture, mathematical models, API references, and run guides.

## Quick Start Commands

1. **Install Dependencies:**
   ```bash
   pip install -r DG_Monitoring_System/backend/requirements.txt
   ```

2. **Run All Automated Tests:**
   ```bash
   cd DG_Monitoring_System/backend
   python -m unittest discover -s tests -v
   ```

3. **Start the Web Application:**
   ```bash
   cd DG_Monitoring_System/backend
   python app.py
   ```

4. **Access the Dashboard:**
   Open [http://localhost:5000](http://localhost:5000) in your web browser.

Deterministic Rule-Based Check: Post-Mains Restoration Shutdown Delays

Strict timestamp comparison: flags unnecessary fuel burn when generator ran after public electricity was restored

Threshold: 10 min

When the public grid (mains) power returns, an ideal automatic transfer switch (ATS) cools down and shuts down the generator within 5 to 10 minutes. If the generator continues running past the configured threshold, unnecessary diesel expenditure occurs. This rule-based verification is strictly independent from machine learning anomaly detection.

Architecture & Engineering Design

College Mini-Project Technical Specifications

Modular Data-Access Layer

Implemented in data_service.py. Encapsulates CSV dataset storage with boundary validation, type coercion, and safe filtering. Designed as an abstract repository interface ready for seamless migration to MySQL without altering frontend logic.

Dual-Engine AI Anomaly Screening

Combines Scikit-learn Isolation Forest with a pure-Python fallback (Liu, Ting, Zhou - IEEE ICDM 2008) to guarantee execution across standard and restricted policy environments. Evaluates feature interactions across load, capacity, runtime, and fuel rate.

Deterministic Delay Verification

Maintains strict separation between machine-learning statistical outliers and deterministic rule-based checks on grid restoration timestamps.
